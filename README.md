## Menjalankan Program

### Persyaratan Sistem

Pastikan program berikut sudah terpasang di sistem Anda:
* Python 3.10 atau lebih tinggi
* Pip 23.0 atau lebih tinggi

### Cara Menjalankan

1. *Clone repository*, lalu buat *virtual environment* di *root* dan aktifkan.
```sh
git clone https://github.com/aufafaza/IF3170_G11_besokaja
cd IF3170_G11_besokaja

python3 -m venv .venv
source .venv/bin/activate
```

2. *Install* dependensi. Pastikan versi Python dan Pip terpenuhi.
```sh
python -m pip install -e .
```

3. Buka Notebook, lalu jalankan pada virtual environment yang sudah dibuat.
